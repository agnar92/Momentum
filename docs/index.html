MOMENTUM // GLB + marża operacyjna ⟳ Odśwież dane
Zasady

Warunki: obrót dzienny ≥ 50 mln $, przychody kw. ≥ +15 % r/r, marża operacyjna ≥ +3 pp r/r (SEC). Kolejność: od największej zmiany marży operacyjnej.

Wejście — Green Line: rekord wszech czasów na zamknięciach miesięcznych, który stoi ≥ 3 zamknięte miesiące (po nowym rekordzie obowiązuje stara linia, dopóki nowy nie przestoi 3 miesięcy). Kupno, gdy tydzień zamknie się 0–10 % nad linią. WYBICIE = ten tydzień nad linią, poprzedni pod; SYGNAŁ = 0–10 % nad; NAD = dalej; POD.

Wyjście: tygodniowy MACD (12, 26, 9) — po przecięciu sygnału w dół stop pod Low tego tygodnia; do tego stop 10 % pod wejściem.

Heurystyka z backtestu (płynny rynek USA 2015–2026), nie porada inwestycyjna.
