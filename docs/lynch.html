Lynch: szybka ocena spółki

Wpisz ticker — 7 pytań Petera Lyncha, odpowiedź z danych i wykres. Dane z –.

Kandydaci wg Lyncha

Spółki, które dziś przechodzą sito Lyncha dla swojego typu (bez ⬇, bez sygnałów sprzedaży i ostrzeżeń „czego unikać”, cena odpowiednia dla typu). Kliknij, żeby ocenić.
Informacyjnie, nie rekomendacja. Spółki wybierasz sam — Lynch kupował dopiero wtedy, gdy znał historię firmy.
